# Security Policy

## Supported Versions

Security fixes are provided for the latest published Halthy release.

## Reporting a Vulnerability

Please report suspected vulnerabilities through GitHub's private security
advisory feature instead of opening a public issue:

1. Open the repository's **Security** tab.
2. Select **Advisories**.
3. Select **Report a vulnerability**.

Include the affected version, Home Assistant version, reproduction steps, and
the security impact. Do not include real health data, workout routes, Home
Assistant access tokens, private server addresses, or other personal data.

If private vulnerability reporting is unavailable, open a minimal issue asking
for a private contact channel without including vulnerability details.
