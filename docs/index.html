Apple Health · Home Assistant

Halthy.

Your health data, connected to the home you control.

Halthy reads the Apple Health metrics you select and can send them directly to your own Home Assistant instance. Optional InfluxDB export keeps your history in a destination you configure.

About Home Assistant sign-in

This page identifies Halthy to Home Assistant and declares the approved return address for the app's sign-in flow. The browser returns directly to the app, not to this website.

Native sign-in is being developed. The currently released app uses manual-token setup; publishing this page does not change that setup or enable the new flow.

No health-data relay

This static page has no sign-in form, scripts or analytics. It does not accept Home Assistant credentials, authentication codes or health data. App-to-server communication remains direct.
